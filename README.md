# Next.js template

This is a Next.js template with shadcn/ui.


## Summary

A fork of [abdulrehmanwaseem/Interactive-3D-Portal](https://github.com/abdulrehmanwaseem/Interactive-3D-Portal). A shader-driven 3D vortex portal synced to audio, built with Next.js.

## What's inside

`app/`, `components/`, `hooks/`, `lib/` and `public/` (the Next.js app), plus `package.json`.

## How to view or run it

Run `npm install`, then `npm run dev`, and open http://localhost:3000. The upstream live version is at https://interactive-3d-portal.vercel.app.
